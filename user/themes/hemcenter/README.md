# Тема hemcenter

Тема сайта Центра гематологии. Обычный CSS без сборки — правится напрямую,
в деплое не нужны node и npm.

## Включение и откат

```yaml
# user/config/system.yaml
pages:
  theme: hemcenter              # откат: bootstrap4-open-matter
```

Старая тема не удалена и остаётся рабочей. Более того, `hemcenter.yaml`
объявляет её запасным источником шаблонов: если какой-то редкий тип страницы
здесь не переопределён (`presentations`, `h5p`, `iframe` и т. п.), Grav возьмёт
шаблон из `bootstrap4-open-matter`, и сайт не упадёт.

## Что где

```
css/theme.css     дизайн-система: токены, типографика, шапка, лента, футер
css/compat.css    мост к Bootstrap-разметке шаблонов плагинов
js/site.js        только мобильное меню
languages.yaml    строки интерфейса на kk / ru / en
templates/        шаблоны страниц и партиалы
```

### Про compat.css

Шаблоны плагинов (`online-order-fs`, `checkvkk`, `form`, `login`) свёрстаны на
классах Bootstrap 4. Сами шаблоны намеренно не трогали — там платёжный путь,
и переписывать его заодно с дизайном рискованно. Вместо этого в `compat.css`
описан ровно тот набор классов, который эти шаблоны используют: сетка,
`btn`, `form-control`, `alert`, `card`, отступы.

Если плагин обновится и начнёт использовать новый bootstrap-класс — он просто
не получит оформления. Проверять так:

```bash
grep -rhoE 'class="[^"]*"' user/plugins/*/templates/*.twig | tr ' ' '\n' | sort -u
```

## Главная страница

Шаблон `templates/home.html.twig`, включается через `template: home` во
фронтматтере `user/pages/01.home/default.*.md`. Блоки сверху вниз:

1. **Карусель** — берёт все изображения из папки `user/pages/headerimage/`.
   Чтобы поменять баннеры, достаточно положить туда другие файлы: шаблон
   ничего не хардкодит. Обрезка `cropZoom(1600, 720)` — средствами Grav.
2. **Услуги** — список в `hemcenter.yaml`, ключ `services`. Подписи берутся
   из `languages.yaml`: `THEME.<key>` — заголовок, `THEME.<key>_TEXT` —
   пояснение. Иконки — свои SVG в `templates/partials/icons/`.
3. **Филиалы** — из страниц `/branches`. Адрес, телефон и почта читаются из
   фронтматтера: `branch_address`, `branch_phone`, `branch_email`. Данные
   лежат рядом с контентом и правятся в админке, дублирования нет.
4. Текст самой страницы, затем три последние новости.

Фотографии — собственные, из репозитория. Стоки намеренно не подключались:
для клиники свои снимки убедительнее, и не возникает вопросов с лицензиями.

## Настройка

`user/config/themes/hemcenter.yaml` либо админка:

- `show_sidebar_default` — боковая колонка на страницах, где она не задана
- `chromeless.enabled` — режим без шапки и футера, для встраивания
- `contacts.*`, `social.*` — телефон, почта и соцсети в футере

Тексты футера и меню — в `languages.yaml`, а не в шаблонах: в старой теме они
были захардкожены тройными `if` по языку.

## Оформление

- **Spectral** — заголовки, **Golos Text** — текст. Обе с полной казахской
  кириллицей (ә ғ қ ң ө ұ ү һ і), это было жёстким требованием при выборе.
- Тёмная тема по `prefers-color-scheme`, стили для печати, `prefers-reduced-motion`.
- Ширина текста ограничена ~42rem: на сайте много длинных медицинских текстов.

Шрифты пока подключаются с Google Fonts. Для боевого сайта их лучше положить
локально — минус внешняя зависимость и меньше данных о посетителях уходит
третьей стороне.

## Локальный запуск

```bash
php -S 127.0.0.1:8081 system/router.php
```

Нужен `composer install` (папки `vendor/`, `images/`, `tmp/`, `backup/` под
`.gitignore` и в репозитории отсутствуют). Локальные оверрайды окружения —
в `user/localhost/config/system.yaml`: на бою кеш на APCu, локально расширения
обычно нет, поэтому там файловый драйвер. Боевой `user/config/system.yaml`
этим не затрагивается.
